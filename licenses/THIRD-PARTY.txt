NexGet Download Manager bundles these open-source programs, each under its own licence. They run as separate,
unmodified programs (FFmpeg is built from unmodified source; see FFmpeg-BUILD.txt).

  aria2 1.37.0           GPL-2.0-or-later   https://github.com/aria2/aria2          (multi-connection downloads)
  yt-dlp 2026.10.21      Unlicense          https://github.com/yt-dlp/yt-dlp        (video; its bundled libraries are listed in tools\yt-dlp\_internal\THIRD_PARTY_LICENSES.txt)
  FFmpeg n9.0.2          LGPL-2.1-or-later  https://ffmpeg.org/  source: https://github.com/FFmpeg/FFmpeg/tree/n9.0.2
  QuickJS-ng 0.17.0      MIT                https://github.com/quickjs-ng/quickjs   (JavaScript runtime used by yt-dlp)

The .NET Framework that runs NexGet ships with Windows.
